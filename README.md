# Computer-Science-A-Level-Project
NEA Project

_Note_: For my course, this component made up 20% of my final grade. I achieved a grade "A" for this component.

The project consisted of two fundemental elements, programming and written documentation, where the written documentation was broken down further, into four elements (analysis of a chosen problem, design of a solution to the chosen problem, development of the solution and evaluation). _Details below._

**Analysis of the Problem:**
With a passion in aviation and aerospace technology, I had noticed that there are numerous different applications available where users can view and manage data, both personally and commercially, from individual flight tickets, at a basic level, to entire fleets of aircraft, at a more advanced level. However, there are fewer applications that integrate this into a singular collaberative environment.

For example, should you fly to a destination requiring connecting flights, through separate airlines, you will typically need separate applications.

As a solution to this issue, I developed an application where personal users could register their upcoming flight details and see all information in one place, including live notifications (from FlightRadar24 API integration) for estimated time of departure, estimated arrival terminal and luggage handling, etc. Commercial users, such as airlines, (secured with domain authentication upon sign-up) could register aircraft within their fleet and recieve live notifications (from the same API service) from these aircraft, via tracking networks, such as ADS-B, satellite and space, etc.

"Analysis of the Problem" also includes researching existing solutions, different computational approaches and the requirements I want to achieve (backed by primary and secondary research).

**Design of the Solution:**
Including UI designs, the structure of data and the locally hosted database it is stored within and pseudocode interpretations of my ideas.

**Development of the Solution:**
Including development and testing.

**Evaluation:**
Including post-development testing and success-criteria testing and which attributes were met, partially met or not met, general limitations, future develpopment, etc.
